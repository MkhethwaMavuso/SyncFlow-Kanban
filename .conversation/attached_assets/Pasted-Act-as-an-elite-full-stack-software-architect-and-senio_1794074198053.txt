Act as an elite full-stack software architect and senior MERN stack developer. Your task is to generate and deploy a complete, production-ready, real-time collaborative Kanban platform (comparable to a lightweight, high-performance Jira/Trello alternative).

### 1. App Overview & Objective
- **Application Name:** SyncFlow Kanban (or similar collaborative name)
- **Core Purpose:** Solve distributed team bottlenecks by providing real-time board updates, drag-and-drop task management, and live multi-user visibility across sprints.
- **Tech Stack:** 
  - **Frontend:** React (Vite), Tailwind CSS, Lucide React (Icons), DnD library (e.g., `@hello-pangea/dnd` or `dnd-kit`), and `socket.io-client`.
  - **Backend:** Node.js, Express.js, and `socket.io` for real-time WebSocket communication.
  - **Database:** MongoDB with Mongoose ODM.

---

### 2. Core Functional Requirements
1. **User Authentication & Authorization:**
   - Secure user registration and login using JWT (JSON Web Tokens) and bcrypt password hashing.
   - Role-based visibility or member association for boards.
2. **Real-Time Kanban Board & WebSockets:**
   - Real-time synchronization: When User A drags a task card from "In Progress" to "Done", User B's board updates instantly without requiring a page refresh via WebSockets (`socket.io`).
   - Columns: Backlog, To Do, In Progress, In Review, Done.
   - Task CRUD: Create tasks, assign members, set priority (Low, Medium, High, Urgent), add due dates, and write comments.
3. **Sprint Tracking & Analytics Dashboard:**
   - Visual metrics tracking sprint progress (e.g., total tasks vs. completed tasks, velocity charts, or burndown indicators).
   - Filter tasks by assignee, priority, or sprint cycle.

---

### 3. Detailed Database Design (Mongoose Schemas)
Implement the following database schemas with proper indexing and relational references:

- **User Schema (`models/User.js`):**
  - `name`: String, required
  - `email`: String, required, unique, lowercase
  - `password`: String, required (hashed)
  - `avatar`: String (optional profile image URL)
  - Timestamps (`createdAt`, `updatedAt`)

- **Board / Workspace Schema (`models/Board.js`):**
  - `title`: String, required
  - `members`: Array of ObjectIds referencing `User`
  - `columns`: Array of Column sub-documents or references

- **Task Schema (`models/Task.js`):**
  - `title`: String, required
  - `description`: String
  - `status`: Enum `['Backlog', 'Todo', 'In Progress', 'Review', 'Done']`, default `'Backlog'`
  - `priority`: Enum `['Low', 'Medium', 'High', 'Urgent']`, default `'Medium'`
  - `board`: ObjectId referencing `Board`
  - `assignee`: ObjectId referencing `User`
  - `dueDate`: Date
  - Timestamps (`createdAt`, `updatedAt`)
